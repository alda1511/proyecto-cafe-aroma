## Descripción 📝

Café Aroma es una página web de una cafetería donde se puede conocer el negocio, sus productos, servicios y formas de contacto.

## Tecnologías utilizadas 💻

- HTML
- CSS
- Git
- GitHub

## Donde utilizamos Flexbox? 📏

Utilizamos Flexbox en la barra de navegación para organizar los enlaces del menú de forma horizontal y ordenada.

## Donde utilizamos Grid? 🔲

Utilizamos Grid en la sección de productos para organizar los productos en filas y columnas.

## Variables CSS 🎨

Creamos variables CSS para guardar los colores principales, colores secundarios, color de fondo, color del texto y los espacios utilizados en la página.

## Responsive Design 📱
 
Implementamos Responsive Design mediante Media Queries para adaptar la página a pantallas más pequeñas. En celulares, el menú pasa a mostrarse de forma vertical y los productos se organizan en una sola columna.

## SEO <>

Utilizamos diferentes estrategias de SEO, como el título de la página, meta descripción, palabras clave, textos alternativos en las imágenes y encabezados organizados.
